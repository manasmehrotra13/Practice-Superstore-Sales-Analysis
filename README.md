# Superstore Sales Analysis

Guided practice project (Nov 2024), built by following a YouTube tutorial.

**What it is:** a Power BI dashboard on the Superstore sales dataset: sales and profit by region, category, segment and month.

**Files:** `superstore sales dashboard.pbix` (the Power BI file), `Super store dashboard.pdf` (a printout), the CSV data.

**What I learned:** loading and modelling data in Power BI, writing basic DAX measures, and building filters and charts.
