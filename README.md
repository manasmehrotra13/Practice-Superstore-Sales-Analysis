# Superstore Sales Analysis

> Guided practice project (Oct–Nov 2024), built by following a YouTube tutorial.

A Power BI dashboard on Superstore sales data.

## The data
About 5,900 orders: order date, region, state, category and sub-category, segment, ship mode, payment mode, sales, profit and quantity.

## What I did
- Loaded the data into Power BI and wrote DAX measures.
- Built a "Store Dashboard" page with 15 visuals: cards for sales, profit, quantity and ship days; sales by category, sub-category, ship mode, segment, payment mode and region; monthly sales and profit compared year on year; a map by state; and a region filter.
- Added a "Sales Forecasting" page with a sales-over-time line chart.

## Tools
Power BI, DAX.

## Files
- `superstore sales dashboard.pbix`: the Power BI file
- `Super store dashboard.pdf`: a PDF of the dashboard
- `SuperStore Sales Raw data.csv` and `SuperStore_Sales_Dataset - Copy.csv`: the data
- `blue background.jpg`: the dashboard background

## What I learned
Loading and shaping data in Power BI, writing basic DAX measures, and building cards, charts, maps and filters.
